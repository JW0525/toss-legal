인스타페북맞팔리포트 개인정보처리방침

시행일 2026년 8월 13일

인스타페북맞팔리포트(이하 “서비스”)는 회원가입이나 토스 로그인을 요구하지 않아요. 이용자가 선택한 Meta 정보 내보내기 파일과 분석 결과는 운영자 서버로 전송하지 않고 이용자의 기기에서 처리해요.

1. 처리하는 정보와 위치

구분내용처리 위치
분석 원본이용자가 직접 선택한 Instagram·Facebook ZIP, JSON 또는 HTML 내보내기 파일과 그 안의 사용자 이름·표시 이름·친구 및 팔로우 관계이용자의 기기 메모리
기기 저장 분석 기록Instagram 사용자 이름·팔로우 관계 또는 Facebook 친구 이름, 원본에 포함된 표시 이름·기록 시각, 분석 시각, 플랫폼 구분이용자의 기기 저장소에 플랫폼별 변화 비교 최근 12회와 가장 최근 분석 리포트 1건
내보내기·공유 정보이용자가 요청한 관계 CSV에는 계정 이름·표시 이름·관계 분류·원본 기록 시각이 포함될 수 있고, 요약 공유에는 계정 이름을 포함하지 않음이용자가 선택한 기기 저장 위치 또는 공유 대상
문의 정보이용자가 이메일로 문의할 때 보내는 이메일 주소, 문의 내용과 회신 기록이메일 서비스와 운영자의 메일함

2. 처리 목적과 수집 방법

  • Instagram 맞팔·일방 팔로우 관계 또는 Facebook 친구 관계 분류
  • 이전 분석 기록과 현재 관계를 비교한 변화 내역 및 최근 분석 리포트 재열기 제공
  • 이용자가 요청한 관계 CSV 생성과 이름 없는 결과 요약 공유
  • 이메일 문의 답변과 분쟁 처리

분석 원본은 이용자가 파일을 선택할 때 처리하고, 변화 비교 기록과 가장 최근 분석 리포트는 분석이 끝날 때 해당 기기에 저장해요. 운영자는 서비스에서 쿠키, 광고 식별자 또는 별도 분석 도구를 이용해 개인정보를 자동 수집하지 않아요.

3. 보유 기간과 파기

  • 분석 원본은 기기 메모리에서 분석한 뒤 별도 저장하지 않으며, 분석 처리 또는 이용 세션이 끝나면 메모리에서 해제돼요.
  • 변화 비교 기록은 플랫폼별 최근 12회, 최근 분석 리포트는 플랫폼별 1건만 보관해요. 12회를 넘으면 오래된 변화 기록부터 교체되고 새 분석을 하면 이전 리포트가 교체되며, 이용자가 기록을 지우거나 토스 미니앱 데이터를 삭제하면 함께 삭제돼요.
  • 기기에 저장한 CSV는 이용자가 기기의 파일 관리 기능으로 삭제할 때까지 유지돼요.
  • 이메일 문의 정보는 답변과 처리 목적이 끝난 뒤 지체 없이 삭제해요. 다만 관계 법령에 보관 의무가 있으면 해당 기간 동안 보관할 수 있어요.

4. 제3자 제공과 처리 위탁

서비스 기능은 분석 원본과 관계 분석 정보를 운영자 서버나 제3자에게 제공하거나 처리를 맡기지 않아요. 다만 이용자가 CSV 저장 또는 요약 공유를 직접 실행하면 이용자가 선택한 저장 위치나 공유 대상에서 해당 정보가 처리돼요. 이메일 문의를 보내면 이용자와 운영자가 사용하는 이메일 서비스의 정책이 적용돼요.

5. 이용자의 권리와 기록 삭제 방법

첫 화면의 ‘저장된 변화 기록 보기’ 또는 분석 결과의 ‘팔로워 변동 내역 보기’·‘친구 변동 내역 보기’로 들어간 뒤, ‘저장된 기록 관리’에서 ‘기록 지우기’를 누르면 해당 플랫폼의 변화 기록과 최근 분석 리포트를 모두 삭제할 수 있어요. 별도로 저장한 CSV는 기기의 파일 관리 기능에서 직접 삭제해 주세요.

운영자는 기기에만 저장된 변화 기록과 최근 분석 리포트를 보거나 직접 열람·정정·삭제할 수 없어요. 이메일 문의 정보에 관한 열람·정정·삭제·처리정지는 아래 문의처로 요청할 수 있어요.

6. 안전성 확보 조치

  • 원본 파일을 기기 안에서만 분석하고 운영자 서버로 전송하지 않음
  • 계정 비밀번호나 로그인 정보 입력을 요구하지 않음
  • 변화 비교에 필요한 정보는 최근 12회, 다시 열 최근 분석 리포트는 1건으로 제한해 저장
  • 앱 안에서 저장 기록을 삭제할 수 있는 기능 제공

7. 다른 사람의 정보가 포함된 파일

Meta 내보내기 파일과 CSV에는 다른 사람의 사용자 이름이나 표시 이름이 포함될 수 있어요. 이용자는 본인이 정당하게 내려받은 파일만 분석하고, 결과를 저장하거나 공유할 때 다른 사람의 권리를 침해하지 않도록 관리해야 해요.

8. 서비스 관계 안내

인스타페북맞팔리포트는 Instagram, Facebook 또는 Meta가 제공하거나 후원하는 서비스가 아니에요.
