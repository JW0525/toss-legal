# 토스 미니앱 약관

앱인토스 미니앱들이 쓰는 **서비스 이용약관**과 **개인정보 수집·이용 동의** 문서입니다.
토스 로그인 동의 화면에서 이 주소를 열기 때문에 **공개 저장소**여야 합니다.

GitHub Pages 로 서빙합니다. `main` 에 push 하면 자동 배포돼요.

## ⛔ 비공개로 바꾸지 마세요 (2026-08-07 실제로 해 보고 되돌림)

**무료 플랜에서는 비공개 저장소로 GitHub Pages 를 못 씁니다.** 비공개로 바꾸는 순간
**Pages 설정 자체가 삭제되고**, 사이트가 통째로 404 가 됩니다 — 이 저장소 하나에
세 앱(쑥쑥가든·데일리 브레인·타로)의 약관이 다 들어 있어서 **셋 다 같이 죽습니다.**

⚠️ 바꾼 직후에는 CDN 캐시 때문에 잠깐 200 이 나옵니다. **살아 있다고 착각하기 쉽습니다.**

되돌리는 법 (겪었을 때):
1. `gh repo edit <repo> --visibility public --accept-visibility-change-consequences`
2. `gh api -X POST repos/<repo>/pages -f 'source[branch]=main' -f 'source[path]=/'`
3. **빈 커밋을 하나 push** 해 새 빌드를 태웁니다 — 2번만으로는 빌드가 안 끝났습니다
4. 모든 앱의 terms/privacy 가 200 인지 확인

여기 담기는 건 약관 문서뿐이라 공개돼도 문제가 없습니다. 비밀값은 들어가지 않습니다.

```
https://jw0525.github.io/toss-legal/<appName>/terms.html
https://jw0525.github.io/toss-legal/<appName>/privacy.html
```

## 폴더 구조

```
toss-legal/
├── index.html          앱 목록
├── style.css           공통 스타일 (모바일·라이트 모드 고정)
├── dailybrain/         매일 두뇌퀴즈 (토스 로그인 씀)
│   ├── index.html
│   ├── terms.html      서비스 이용약관
│   └── privacy.html    개인정보 수집·이용 동의
├── ssukgarden/         쑥쑥가든 (토스 로그인 씀 · 꿀 → 포인트 교환)
│   ├── index.html
│   ├── terms.html      서비스 이용약관
│   └── privacy.html    개인정보 수집·이용 동의
└── tarot-answer/       타로 한 장의 답 (로그인 없음)
    ├── index.html
    ├── terms.html      서비스 이용약관
    └── privacy.html    개인정보 처리방침
```

**앱마다 문서 이름이 다를 수 있습니다.** 토스 로그인을 쓰면 이름을 동의받으므로
「개인정보 수집·이용 **동의**」가 되고, 로그인이 없으면 동의받을 게 없어
「개인정보 **처리방침**」입니다. 앱이 실제로 하는 일에 맞추세요.

⚠️ **앱 안의 글과 이 페이지는 같은 말이어야 합니다.** 두 곳이 다르면 심사에서 걸려요.
타로는 `applications/tarot/src/lib/legal.ts` 가 원본입니다 — 거기를 고치면 여기도 같이 고치세요.

**앱을 추가할 때는 `appName` 으로 폴더를 만들고** `dailybrain/` 을 복사해서 고치세요.
`style.css` 는 루트 하나를 공유하므로 앱 폴더에서는 `../style.css` 로 참조합니다.
`index.html` 에 그 앱 항목도 추가하세요.

## 아직 넣지 않은 것

되살리자는 요청이 오면 이 표부터 읽고 판단하세요.

| 뺀 것 | 언제 | 왜 |
|---|---|---|
| 사업자 정보 (상호·대표자·등록번호·주소) | 2026-08-05 | 「수집·이용 동의서」는 수집항목·목적·보유기간·거부권리만 있으면 되고 사업자 정보가 법적 필수가 아닙니다. 개인사업자라 대표자 실명과 집 주소가 그대로 공개되는 것도 미뤘어요. **정식 「개인정보 처리방침」을 만들 때는 넣어야 합니다** |
| 개인정보 처리 위탁 항목 | 2026-08-05 | 서버 호스팅을 아직 정하지 않았습니다 (`daily-brain/docs/hosting.md` 에 후보만 있음). 없는 업체를 적는 것보다 비워 두는 쪽이 정확해요. **서버를 배포하면 반드시 추가하세요** |
